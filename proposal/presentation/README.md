# Meme Coin Analysis Dashboard 발표 자료

**개정 상태:** [7분 발표 구성안](slide-outline.md)이 현재 편집 기준이다. 아래 PPT·PDF는 기존 18장 초안이며, 8장 구성과 CMC 크롤링·MemeChain 참고 자료 구분은 아직 슬라이드 파일에 반영하지 않았다.

[PowerPoint 열기](memecoin-analysis-dashboard.pptx) · [PDF 보기](memecoin-analysis-dashboard.pdf) · [출처와 이미지 크레딧](sources.md)

영문 슬라이드 **18장**으로 구성했습니다. 1–15장은 본 발표, 16–18장은 질문 대응과 출처 부록입니다. 본문 약 10–12분을 가정했으며 공식 발표 시간은 아직 미정입니다. 각 슬라이드의 발표자 노트에는 한국어 설명과 관련 출처가 있습니다.

## 내용과 사용

- 1–4장: 프로젝트 소개, TRUMP 차트, 문제 정의와 연구 질문.
- 5–7장: 가격 데이터, X·Reddit 수집 범위, MemeChain 링크 검증.
- 8–11장: 데이터 흐름, PostgreSQL·MongoDB 선택, 전처리와 배치 운영.
- 12–15장: 대시보드 구상, 결측·수집 상태, 평가 기준과 6주 일정.
- 16–18장: 저장 모델, 소스별 한계와 출처.

TRUMP 차트는 첨부 데이터의 전체 제공 기간인 **2025-01-18–2026-10-07**의 일별 종가 628개를 사용합니다. “what you want / after you buy”는 발표용 농담이며, 실제 거래나 현재 시세를 나타내지 않습니다. 최고점 표시는 장중 최고가가 아닌 **최고 일별 종가**입니다.

대시보드 화면은 구현 예정인 구성입니다. DOGE 가격은 실제 제공 자료이고 소셜 영역은 아직 수집하지 않은 상태로 표시했습니다. 성능과 표본 검토 수치는 향후 검증 목표입니다. Reddit 수집은 기존 Proposal의 접근 조건을 그대로 따릅니다.

## 디자인과 편집

shadcn/ui와 Geist를 참고해 흑백 중심 색상, 여백, 얇은 경계선과 일관된 타이포그래피를 사용했습니다. 색상은 데이터 흐름과 상태를 구별할 때 사용합니다. 사진·로고 14개를 포함하며 출처는 노트와 별도 문서에서 확인할 수 있습니다.

본문은 Geist, 코드와 보조 표기는 Geist Mono입니다. 다른 기기에서 PPT를 편집할 때는 [공식 Geist 폰트](https://vercel.com/font)를 설치하면 글꼴 대체를 피할 수 있습니다. 글꼴 파일은 PPT에 포함하지 않았습니다. PDF는 읽기와 공유용입니다.

차트 2개와 표 4개, 흐름도는 PowerPoint에서 편집할 수 있습니다. 차트에는 사용한 값의 Excel 통합문서 스냅샷이 포함됩니다. 원본 수집기를 실행하거나 외부 시세와 자동 동기화하는 연결은 없습니다.

기준 문서는 [영문 Proposal](../project-proposal.md), [근거 문서](../evidence-and-references.md), [한국어 아키텍처](../../architecture/README.md)입니다. 자료를 수정할 때는 데이터 기준일과 노트의 출처도 함께 갱신해야 합니다.
